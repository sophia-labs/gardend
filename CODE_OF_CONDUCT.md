# Code Of Conduct

This project expects direct, respectful collaboration focused on the work.

## Standards

- Be specific, factual, and constructive in technical discussion.
- Critique code, architecture, tests, and release risks without personal attacks.
- Respect privacy and do not post secrets, private user data, local profile
  contents, or unreleased security details.
- Keep feedback actionable: explain the observed behavior, expected behavior,
  and why the change matters.

## Unacceptable Behavior

- Harassment, threats, discrimination, or sustained personal hostility.
- Publishing private security reports, credentials, local tokens, or user data.
- Disruptive behavior that prevents maintainers or contributors from evaluating
  technical work.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate
these standards, and may restrict participation for repeated or severe
violations. Security-sensitive reports should follow `SECURITY.md`.
